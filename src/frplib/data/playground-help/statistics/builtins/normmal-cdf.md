# Normal Cumulative Distribution Function

The statistic `NormalCDF` computes the Normal Cumulative Distribution
Function, a special function determined by the standard Normal distribution.
It accepts and returns a scalar, giving an error for non-scalar input.

Examples
+ `NormalCDF(0)` => <0.5>
+ `NormalCDF(3)` => <0.9986501019683699>
+ `NormalCDF(2)` => <0.9772498680518208>
+ `NormalCDF(5)` => <0.9999997133484282>
