# The __ (hole) Statistic and Friends

`__` (pronounced "hole") is a statistic that simply returns the input it receives.

The primary use for hole is as a stand-in for the input to a statistic expression.
(See topic *Statistic Expressions* for more examples.)

For instance, the statistic `(2 * __)` takes its input and scales every
component by 2:

+ `tup(1, 2, 3) ^ (2 * __)` returns <2, 4, 6>
+ `(2 * __)(10, 20, 10, 0)` returns <20, 40, 10, 0>
  
Hole can be used multiple times in such an expression, standing for the same
input each time, e.g., `(3 * __ + __)`.

There are three related statistics worth noting:

+ `Id` (for identity) is a synonym for `__`. This has a slightly different
  feel to it than hole, but is equivalent. For example, to create a statistic
  that appends the sum of compoennts to a tuple, we would do `Fork(Id, Sum)`,
  but this is a stylistic choice.
  
+ `Scalar` is like hole, but it requires that its input be a scalar and will
  raise an error if the input is not. This is useful as a substitute for
  hole when you want to ensure a scalar, e.g., `(Scalar % 2)`.

+ `_x_` is synonym for `Scalar`
