# The Gamma and Log-Gamma Functions

`Gamma(x)` computes the Gamma function at `x`, and `GammaLn(x)` computes
the log of the Gamma function at `x`. `Gamma(n) = (n - 1)!` for positive
integer `n`. The `Gamma` function is defined at all real numbers
except for 0 and the negative integers.

Examples
+ `Gamma(4)` => <6>
+ `GammaLn(1)` => <0>
