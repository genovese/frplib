# Hyperbolic Trigonometric Functions

The statistics `Sinh`, `Cosh`, and `Tanh` compute the hyperbolic
tangent functions. All accept and return scalar tuples. They give an
error message for non-scalar inputs.


+ `Sinh` computes the hyperbolic sine
+ `Cosh` computes the hyperbolic cosine
+ `Tanh` computes the hyperbolic tangent

Examples:

+ `Sinh(1)` => <1.175201193643801>
+ `Cosh(0)` => <1>
+ `Tanh(2)` => <0.9640275800758169>
