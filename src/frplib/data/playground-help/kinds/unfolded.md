# unfolded

`unfolded(k)` displays a Kind `k` in fully unfolded form.

The returned object is designed to display that way in
the playground; you can also do `str()` on that object
to get the string form.

`unfold` is currently an alias for `unfolded` from
earlier versions of the library.

**Note**: `unfold` will be DEPRECATED in v0.4.1 and
`unfolded` will become more general.
