# Builtin Condition Factories

+ `Between` :: `Between(a, b)` tests if its input is between `a` and `b`, optionally including the upper bound.

+ `Contains` :: `Contains(v)` tests if the specified tuple `v` is within its input tuple as a contiguous subsequence.
none.

+ `ElementOf` :: `ElementOf(coll)` tests if its input value belongs to collection `coll`.
