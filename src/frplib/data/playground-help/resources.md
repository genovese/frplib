# Resources

Besides the built-in help in the `info()` system,
you can access several resources from within
the playground:

+ `cheatsheet()` :: displays or copies the frplib Cheatsheet
+ `cookbook()` :: displays or copies the frplib Cookbook
+ `textbook()` :: displays or copies the version of the
  text *Probability Explained* that is bundled with `frplib`.

Note that in a class you might have access to a slightly more recent
version of the book.

The book *Probability Explained* has extensive coverage of `frplib`
and many examples that show how to use in to solve practical
problems. The text is the single best source for learning to use the
software. Most significant examples have an `frplib.examples`
module, and the book is designed for the reader to follow along in
many parts from within the playground.

The source code repository [frplib](https://github.com/genovese/frplib)
has the code and complete installation instructions.
