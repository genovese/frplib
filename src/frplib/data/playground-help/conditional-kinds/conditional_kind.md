# The `conditional_kind` Function

The `conditional_kind` function constructs Conditional Kindss from a
variety of sources. It can be used as a function that accepts
dictionaries, functions, or conditional Kinds or used as a decorator
on function definitions.

The signature is
```
    conditional_kind(
        mapping=None,
        *,
        codim=None,
        dim=None,
        domain=None,
        target_dim=None
    )
```

This converts a mapping from values to Kinds (dictionary or function)
into a conditional Kind.

If the `mapping` is a *dictionary*, it should associating values
(scalars or vector tuples) to Kinds. Scalar keys in the dictionary
can be numbers or tuples; they will be automatically wrapped in a
tuple during processing. In this case, `conditional_kind` can infer
both the domain and the codimension automatically from the
dictionary's keys. It can also infer the dimension from the
Kinds in the dictionary.

If `mapping` is a Conditional FRP, the resulting Conditional Kind is
generated by taking the Kinds of the target FRPs for each valid
input value.

If `mapping` is a conditional Kind and none of its attributes are
being changed by the other arguments, return it as is. Otherwise,
the conditional Kind is treated as a function.

If `mapping` is another function, it should map to values to Kinds.
When this function takes a single argument, it will be assumed to be
a tuple, unless `codim=1` in which case the argument is passed as
is. Multiple arguments, including starred arguments are allowed and
both specify the codim and destructure the input tuple accordingly
for the body of the function.

If `mapping` is missing, this function acts as a decorator on the
function definition following.

Parameters:

codim: int | tuple[int, int] | None -- the codimension of the
    conditional Kind, i.e., the dimension of the input values. If
    not specified (None), then any length tuple is accepted. If set
    explicitly to 1, then a wrapped function should accept a scalar
    argument. If codim is a tuple (a, b), then the codim can be
    any value from a through b. (Default: None)

dim: int | None -- the final dimension of the join Kind. If None, the
    dimension is unknown and unconstrained.

target_dim: int | None -- the dimension of the target Kinds. This can be supplied
    in lieu of dim and is often more convenient.

domain -- the domain of the conditional Kind; either an iterable or a
    predicate that returns true for a valid input.

Returns a ConditionalKind, if mapping supplied, or a decorator otherwise.
