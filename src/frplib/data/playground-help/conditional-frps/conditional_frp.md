# The `conditional_frp` Function

The `conditional_frp` function constructs Conditional FRPs from a
variety of sources. It can be used as a function that accepts
dictionaries, functions, or conditional Kinds or used as a decorator
on function definitions.

The signature is
```
    conditional_frp(
        mapping=None,
        *,
        codim=None,
        dim=None,
        domain=None,
        target_dim=None,
        auto_clone=False
    )
```

This converts a mapping from values to FRPs or Kinds (dictionary or
function) into a conditional FRP.

If the `mapping` is a *dictionary*, it should associating values
(scalars or vector tuples) to FRPs or Kinds. Any values of the
dictionary that are Kinds rather than FRPs are converted to fresh
FRPs with `frp`. Scalar keys in the dictionary can be numbers or
tuples; they will be automatically wrapped in a tuple during
processing. In this case, `conditional_frp` can infer both the
domain and the codimension automatically from the dictionary's keys.
If the returned FRPs have a Kind already, it can also infer the
dimension.

If `mapping` is a Conditional Kind, the resulting Conditional FRP
is generated by creating fresh targets with the corresponding Kinds
for each valid input value.

If `mapping` is a conditional FRP and none of its attributes are
being changed by the other arguments, return it as is. Otherwise,
the conditional FRP is treated as a function.

If `mapping` is missing, this function acts as a decorator on the
function definition following.

If `mapping` is another function, it should map to values to FRPs
(or Kinds). When the function returns a Kind, it is automatically
converted to an FRP. This works as well when using `conditional_frp`
as a decorator on a function definition.

In principle, function as `mapping` *should* return the *same* FRP
each time it is called with any particular value, but by default,
results are cached, so this should not cause problems if violated.
The `auto_clone` option, when set to True, ensures that the FRPs are
explicitly cloned on every evaluation (including joins), see below.

When `mapping` is a function or when this is being used as a
decorator on a function definition and the function takes a single
argument, it will be assumed to be a tuple, unless `codim=1` in which
case the argument is passed as is. Multiple arguments, including
starred arguments are allowed and both specify the codim and
destructure the input tuple accordingly for the body of the function.

Parameters:

codim: int | None -- the codimension of the conditional FRP, i.e.,
    the dimension of the input values. If not specified (None), then
    any length tuple is accepted. If set explicitly to 1, then a
    wrapped function should accept a scalar argument. If codim is a
    tuple (a, b), then the codim can be any value from a through b.
    (Default: None)

dim: int | None -- the final dimension of the join FRP. If None, the
    dimension is unknown and unconstrained.

target_dim: int | None -- the dimension of the target FRPs. This can be supplied
    in lieu of dim and is often more convenient.

domain -- the domain of the conditional FRP; either an iterable or a
    predicate that returns true for a valid input.

auto_clone: bool -- if True, every evaluation of the mapping or targets
    are automatically cloned. The primary use case for this option, which
    defaults to False, is for simulations one wants to reuse the conditional
    FRPs. (Default: False)

Returns a ConditionalFRP, if mapping supplied, or a decorator otherwise.
